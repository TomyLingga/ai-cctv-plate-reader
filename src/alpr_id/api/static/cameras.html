Tambah kamera

Isian bertanda * wajib diisi.

Huruf, angka, tanda hubung atau garis bawah. Dipakai di alamat API dan nama folder gambar, dan tidak bisa diganti setelah disimpan.

Alamat stream RTSP *

Kamera Hikvision: /Streaming/Channels/101 untuk stream utama, 102 untuk sub stream. Merek lain memakai jalur berbeda.

Harus diawali rtsp://. Karakter khusus di dalam sandi, seperti @ atau :, ditulis dalam bentuk persen (%40, %3A).

Antara 1 dan 15. Semua kamera memakai GPU yang sama, jadi tiap kamera baru menambah bebannya.

Angka n untuk /plate/n dan /video/n yang dipakai aplikasi timbangan. Kosongkan bila tidak perlu.

Area baca

Plat hanya dicari di dalam area ini. Persempit ke jalur kendaraan supaya plat tampak lebih besar bagi detektor. Tarik kotak di gambar, atau isi angkanya dalam persen dari tepi kiri dan tepi atas gambar.

Gambar kamera muncul di sini setelah uji sambungan berhasil.
